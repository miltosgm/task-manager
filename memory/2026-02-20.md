### Key Technical Notes

- `c.setFillAlpha()` works for transparency in ReportLab canvas
- `canvas.Canvas(path, pagesize=landscape(A4))` → W=841.89, H=595.276 pts
- Font registration: `pdfmetrics.registerFont(TTFont(name, path))`
- Text wrapping: manual word-split loop using `c.stringWidth()` to measure
- Outbound media path: `/Users/milton/.openclaw/media/outbound/`

### ReportLab Pattern (Reusable)
```python
from reportlab.lib.pagesizes import A4, landscape
from reportlab.lib.units import mm
from reportlab.lib.colors import HexColor, white
from reportlab.pdfgen import canvas
from reportlab.pdfbase import pdfmetrics
from reportlab.pdfbase.ttfonts import TTFont

# draw content...
c.showPage()  # next page
c.save()
```
